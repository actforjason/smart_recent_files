# Smart Recent Files (智能最近文件)

Blender 插件：打开最近文件时实现“修改即存盘并打开”的高效流，同时提供便捷的“强制不保存打开”能力。

---

## 核心特性

1. **自动保存并打开（默认行为）**：
   - 点击最近文件列表项：若当前工程有改动（`is_dirty`），先自动静默保存当前文件，随后打开目标工程。无需再手动点击“Save”。
2. **强制丢弃改动打开（必要时不保存）**：
   - **方式一（快捷键）**：按住 `Shift` 键并点击任意最近文件，直接放弃当前改动并载入。
   - **方式二（子菜单）**：菜单底部提供【不保存直接打开 (丢弃改动)...】子菜单，直接点击即可。
3. **未命名工程防丢保护**：
   - 若当前工程从未存过盘（新建未命名状态），点击打开其他文件时会自动弹出保护对话框，引导用户“先另存为”或“明确确认放弃”，防止心血丢失。
4. **无缝集成**：
   - 自动接管 `File > Open Recent` 菜单位置。
   - 自动绑定 `Shift + Ctrl + O` 快捷键，在任意视图直接浮动弹出最近文件列表。
   - 随时可在插件偏好设置中切换接管模式。

---

## 交互方式一览

| 操作 | 对应行为 |
| :--- | :--- |
| **直接点击文件** | 当前工程有改动时**自动存盘**，然后打开目标工程 |
| **Shift + 点击文件** | **丢弃当前改动**，不保存直接打开目标工程 |
| **展开“不保存直接打开...”子菜单** | 点击直接丢弃改动并打开对应工程 |
| **快捷键 `Shift + Ctrl + O`** | 在鼠标指针处快速弹出智能最近文件菜单 |

---

## 安装方法

1. 将 `smart_recent_files` 文件夹放入 Blender 的 `addons` 或 `extensions` 目录（例如 `B:\scripts\blenderExt\`）。
2. 在 Blender **编辑 -> 偏好设置 -> 插件** 中搜索并启用 `Smart Recent Files`。
